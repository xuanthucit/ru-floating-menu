# ru-floating-menu
RU Floating Menu is a lightweight WordPress plugin that adds a customizable floating menu to your website, helping users quickly access important links while scrolling.

## Installation

### Method 1: Install via WordPress Admin (Recommended)

1. Download the plugin as a ZIP file from this GitHub repository.
2. Log in to your WordPress Admin Dashboard.
3. Navigate to **Plugins → Add New → Upload Plugin**.
4. Select the downloaded ZIP file and click **Install Now**.
5. After installation, click **Activate Plugin**.

---

### Method 2: Install via FTP

1. Download and extract the plugin ZIP file.
2. Upload the extracted plugin folder to the `/wp-content/plugins/` directory using FTP.
3. Log in to your WordPress Admin Dashboard.
4. Go to **Plugins → Installed Plugins**.
5. Locate **RU Floating Menu** and click **Activate**.

---

### After Activation

- Access the plugin settings page from the WordPress Admin Dashboard.
- Configure the floating menu items, position, and appearance.
- Save your settings and refresh your website to see the floating menu.

---

### Requirements

- WordPress 5.0 or higher  
- PHP 7.0 or higher
